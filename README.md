# Exercício de Orientação a Objetos em JavaScript

Este repositório contém a implementação de um exercício proposto no curso da EBAC, com foco na aplicação de conceitos de programação orientada a objetos (POO) em JavaScript.

## Objetivo

- Criar uma classe base (abstração).
- Criar pelo menos duas classes herdeiras da classe principal.
- Criar pelo menos três instâncias de objetos.
- Demonstrar uso de herança, métodos e polimorfismo.

## Estrutura do Projeto

- `Musica`: classe base que representa uma música com título e ano de lançamento.
- `Album`: herda de `Musica`, adiciona uma lista de faixas e um método para listá-las.
- `Single`: herda de `Musica`, informa se o single pertence ou não a um álbum.
